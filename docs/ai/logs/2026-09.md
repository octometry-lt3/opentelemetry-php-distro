## Issue #2 PHP 8.1 scoped runtime memory polyfill

- Fixed scoped PHP package generation so PHP 8.1 exposes a generated global `ini_parse_quantity()` alias when scoped Symfony PHP 8.2 polyfills provide `OTelDistroScoped\ini_parse_quantity()`.
- The fix is implemented in `tools/build/fix_scoped_composer_autoload.php` and avoids `eval()` by generating `vendor/composer/otel_distro_php82_polyfill_aliases.php` and autoloading it after `symfony/polyfill-php82/bootstrap.php`.
- Validated regenerated `scoped/81` on Docker `php:8.1-cli-alpine` and regenerated `scoped/82` on Docker `php:8.2-cli-alpine`; both parse `128M` as `134217728` through `MemoryMetrics::parseMemoryLimit()`.
